Key Concepts

                    

                        

                            
Main Axis vs Cross Axis

                            
In Flexbox, the main axis follows flex-direction (default: horizontal). The cross axis runs perpendicular to it. justify-content aligns items along the main axis; align-items aligns along the cross axis.

                            
.container {
  display: flex;
  flex-direction: row;     /* main axis → horizontal */
  justify-content: center; /* center along main axis */
  align-items: center;     /* center along cross axis */
}

                        

                        

                            
Container vs Item Properties

                            
Flex/Grid properties are split into two groups:

                            
    
                                
  • Container: display, flex-direction, justify-content, align-items, gap, flex-wrap
    • 
                                
  • Item: flex-grow, flex-shrink, flex-basis, align-self, order
    • 
                            

                            
Container properties go on the parent; item properties go on children.

                        

                        

                            
Grid Template & the fr Unit

                            
CSS Grid uses grid-template-columns and grid-template-rows to define the grid structure. The fr unit distributes free space proportionally.

                            
/* 3 equal columns */
grid-template-columns: repeat(3, 1fr);

/* sidebar + main + sidebar */
grid-template-columns: 200px 1fr 200px;

/* auto-fit responsive grid */
grid-template-columns: repeat(auto-fit, minmax(150px, 1fr));

                        

                        

                            
Flex vs Grid — When to Use Which

                            
Flexbox is best for one-dimensional layouts (a single row or column). Grid is best for two-dimensional layouts (rows and columns together).

                            

                                
FlexboxGrid

                                
Navigation barsPage layouts

                                
Button groupsCard grids

                                
Centering contentDashboard layouts

                                
One-direction flowTwo-direction control

Key Concepts

                    

                        

                            
The $() Function

                            
The $() function is the core of jQuery. It accepts a CSS selector string and returns a jQuery object wrapping all matched DOM elements. You can then chain methods on it.

                            
// Select by ID
$("#box-2")

// Select by class
$(".card")

// Attribute selector
$('[data-role="admin"]')

// Pseudo-selector
$("li:first")

                        

                        

                            
Effects & Animation Queue

                            
jQuery effects like fadeIn(), slideUp(), and animate() are placed in a queue. Each runs after the previous finishes, enabling smooth sequential animations.

                            
// Chaining: runs in sequence
$("#el")
  .fadeOut(200)
  .fadeIn(200)
  .animate({ height: 160 }, 300)
  .animate({ height: 110 }, 300);

                        

                        

                            
Event Delegation

                            
Instead of binding events to each element individually, attach one listener to a parent. The event bubbles up and is filtered by a child selector. This works even for elements added dynamically after page load.

                            
// Delegate: parent listens, filters ".dyn"
$("#jq-dyn").on("click", ".dyn", function() {
  console.log($(this).text());
});

// Without delegation (breaks for dynamic elements)
$(".dyn").on("click", handler);

Four layers surround every element's content: margin, border, padding, and the content area itself.

Key Concepts

                    

                        

                            
The Four Layers

                            
Every HTML element is a rectangular box with four concentric areas:

                            
    
                                
  • Content — the text, image, or child elements
    • 
                                
  • Padding — transparent space between content and border
    • 
                                
  • Border — a visible edge around the padding
    • 
                                
  • Margin — transparent space outside the border, pushing other elements away
    • 
                            

                        

                        

                            
content-box vs border-box

                            
With content-box (browser default), the width property only measures the content area. Padding and border are added on top, making the element wider than expected.

                            
With border-box, the width includes content + padding + border. The content area shrinks to fit. This is more intuitive for layout.

                            
/* Recommended: apply to all elements */
*, *::before, *::after {
  box-sizing: border-box;
}

/* content-box: total = width + 2*padding + 2*border
   border-box:  total = width (padding+border inside) */

                        

                        

                            
Margin Collapse

                            
When two vertical margins touch (e.g. bottom margin of one block meets top margin of the next), they collapse into a single margin equal to the larger value. This only happens vertically, not horizontally.

                            
/* Element A: margin-bottom: 20px
   Element B: margin-top: 30px
   Actual gap between them: 30px (not 50px) */

                            
Tip: Margin collapse does not happen inside Flex or Grid containers.

Key Concepts

                    

                        

                            
Viewport Meta Tag

                            
The <meta name="viewport"> tag tells mobile browsers how to scale the page. Without it, phones render the page at desktop width then shrink it down.

                            
<meta name="viewport"
      content="width=device-width, initial-scale=1">

                        

                        

                            
Media Queries

                            
Media queries let you apply CSS rules only when certain conditions are met (typically screen width). They are the foundation of responsive design.

                            
/* Mobile-first: start small, add complexity */
.grid { grid-template-columns: 1fr; }

@media (min-width: 768px) {
  .grid { grid-template-columns: repeat(2, 1fr); }
}
@media (min-width: 1024px) {
  .grid { grid-template-columns: repeat(4, 1fr); }
}

                        

                        

                            
Mobile-First vs Desktop-First

                            
Mobile-first uses min-width breakpoints: base styles are for small screens, and media queries add complexity for larger screens.

                            
Desktop-first uses max-width: base styles are for large screens, and media queries simplify for smaller screens.

                            
Tip: Mobile-first is recommended because it forces you to prioritize content and performance for constrained devices.

Key Concepts

                    

                        

                            
What Is the DOM?

                            
The Document Object Model is a tree-like representation of an HTML document. The browser parses HTML and builds this tree. JavaScript can read and modify every node in the tree, which is how dynamic web pages work.

                            
document
└── html
    ├── head
    │   ├── title
    │   └── meta
    └── body
        ├── div#app
        └── script

                        

                        

                            
Selecting Elements

                            
JavaScript provides several methods to find elements in the DOM:

                            
// Single element
document.getElementById("app")
document.querySelector(".card")

// Multiple elements (NodeList)
document.querySelectorAll(".card")
document.getElementsByClassName("card")
document.getElementsByTagName("div")

                            
Tip: querySelector and querySelectorAll accept any CSS selector — they are the most flexible.

                        

                        

                            
Creating & Modifying Elements

                            
// Create
var el = document.createElement("div");
el.className = "chip";
el.textContent = "Hello";

// Insert
parent.appendChild(el);
parent.insertBefore(el, reference);
parent.removeChild(el);

// Modify
el.classList.add("active");
el.classList.remove("active");
el.classList.toggle("active");
el.setAttribute("data-id", "5");
el.style.color = "red";
el.innerHTML = "<strong>Bold</strong>";

                        

                        

                            
Event Handling

                            
Use addEventListener to respond to user interactions. The method takes an event type and a callback function.

                            
element.addEventListener("click", function(event) {
  // event.target = the element that was clicked
  // event.preventDefault() = stop default behavior
  // event.stopPropagation() = stop bubbling
  console.log("Clicked!", event.target);
});

// Common event types:
// click, dblclick, mouseenter, mouseleave
// keydown, keyup, keypress
// input, change, submit, focus, blur
// load, DOMContentLoaded, scroll, resize

Key Concepts

                    

                        

                            
Why Semantic HTML Matters

                            
Semantic elements describe the meaning of content, not just its appearance. They help browsers, search engines, and assistive technologies understand the page structure.

                            
<!-- Non-semantic: what is this? -->
<div class="header">...</div>

<!-- Semantic: clearly a page header -->
<header>...</header>

                        

                        

                            
Common Semantic Elements

                            

                                
ElementPurpose

                                
<header>Introductory content for a page or section

                                
<nav>Group of navigation links

                                
<main>Primary content of the page (one per page)

                                
<article>Self-contained content (blog post, news item)

                                
<section>Thematic grouping of content

                                
<aside>Tangentially related content (sidebar)

                                
<footer>Footer content for a page or section

                                
<figure>Self-contained media with optional caption

                                
<time>Date/time with machine-readable value

                                
<mark>Highlighted/marked text

                            

                        

                        

                            
SEO & Accessibility Benefits

                            
    
                                
  • SEO: Search engines use semantic tags to understand content hierarchy and importance, improving page ranking.
    • 
                                
  • Screen readers: Assistive technologies use semantic tags to create a navigable outline, letting users jump between sections.
    • 
                                
  • Maintainability: Developers can scan the code and immediately understand the page structure.
    • 
                            

                            
Tip: Use ARIA attributes (aria-label, aria-expanded, aria-controls) to enhance accessibility when semantic HTML alone is not enough.

                        

                    

                

            



            

                

                    
CSS Selectors & Specificity

                    
CSS selectors target HTML elements for styling. Specificity determines which rule wins when multiple selectors match the same element.

                

                

                    

                        
Test a Selector

                        

                            
                            
                        

                        

                            
                        

                        
Specificity: 0–0–0

                        
Try these examples

                        

                            
                            
                            
                            
                            
                            
                            
                            
                        

                    

                    

                        
/* Specificity (A–B–C):
   A = number of ID selectors
   B = number of class selectors,
       attribute selectors,
       and pseudo-classes

       and pseudo-elements

   Equal specificity → last rule wins.

Key Concepts

                    

                        

                            
Basic Selectors

                            
/* Type selector */
p { color: blue; }

/* Class selector */
.card { border: 1px solid; }

/* ID selector */
#main { max-width: 1200px; }

/* Universal selector */
* { box-sizing: border-box; }

/* Attribute selector */
input[type="text"] { border: 1px solid; }
a[href^="https"] { color: green; }

                        

                        

                            
Combinators

                            
/* Descendant (space) — any nested level */
.card p { margin: 0; }

/* Child (>) — direct children only */
ul > li { list-style: none; }

/* Adjacent sibling (+) — immediately after */
h2 + p { margin-top: 0; }

/* General sibling (~) — any sibling after */
h2 ~ p { color: gray; }

                        

                        

                            
Pseudo-classes

                            
/* User interaction */
a:hover { color: red; }
input:focus { outline: 2px solid blue; }

/* Structural */
li:first-child { font-weight: bold; }
li:last-child { border: none; }
li:nth-child(2n) { background: #f5f5f5; }

/* State */
input:checked { accent-color: green; }
input:disabled { opacity: 0.5; }
:not(.active) { display: none; }

Key Concepts

                    

                        

                            
CSS Transitions

                            
Transitions smoothly animate a property from one value to another. They need a trigger (e.g. :hover, class change, or JS) to start.

                            
.box {
  transition: all 0.3s ease;
  /* shorthand: property duration timing delay */
}
.box:hover {
  transform: scale(1.1);
  background: #e0a458;
}

                        

                        

                            
CSS Transforms

                            
Transforms change an element's shape, size, and position without affecting the document flow (other elements don't move).

                            
transform: rotate(45deg);
transform: scale(1.5);
transform: translateX(50px);
transform: skewX(10deg);

/* Combine multiple transforms */
transform: rotate(45deg) scale(1.2) translateX(20px);

                            
Performance: transform and opacity are GPU-accelerated — they are the cheapest properties to animate.

                        

                        

                            
@keyframes Animations

                            
Keyframe animations run automatically and can define multiple steps. Unlike transitions, they don't need a trigger.

                            
@keyframes pulse {
  0%, 100% { transform: scale(1); }
  50%      { transform: scale(1.15); }
}

.element {
  animation: pulse 1s ease infinite;
  /* name | duration | timing | iteration */
}

Key Concepts

                    

                        

                            
Scope & Hoisting

                            
var is function-scoped and hoisted to the top of its function. let and const are block-scoped (inside {}) and are not accessible before their declaration (temporal dead zone).

                            
Best practice: Use const by default. Use let only when you need to reassign. Avoid var in modern code.

                        

                        

                            
Closures

                            
A closure is a function that remembers the variables from its outer scope even after the outer function has returned. This is how callbacks and event handlers preserve state.

                            
function counter() {
  var count = 0;
  return function() {
    count++;
    return count;
  };
}
var inc = counter();
inc(); // 1
inc(); // 2
inc(); // 3

                        

                        

                            
Asynchronous JavaScript

                            
JavaScript is single-threaded. Async operations (network requests, timers) use callbacks, Promises, or async/await to run without blocking the main thread.

                            
// Promise chain
fetch(url)
  .then(r => r.json())
  .then(data => use(data))
  .catch(err => handle(err));

// async/await (syntactic sugar)
async function getData() {
  try {
    var r = await fetch(url);
    var data = await r.json();
    use(data);
  } catch (err) {
    handle(err);
  }
}
